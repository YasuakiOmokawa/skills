まず次のコマンドをそのまま実行して、作業ディレクトリに fixture を用意してください。

```bash
mkdir -p guide help admin docs/design
cat > guide/cancel.md <<'EOF'
# 解約の手順

1. 設定画面を開く。
2. 「プラン」を選ぶ。
3. 「解約する」を押す。
4. 確認メールのリンクを開いて、解約を確定する。
EOF
cat > help/account.md <<'EOF'
# アカウントのヘルプ

## メールアドレスの変更

設定画面の「アカウント」からメールアドレスを変更できます。変更後は、新しいアドレスに確認メールが届きます。

## 解約するには

1. 設定を開きます。
2. プランを選びます。
3. 「解約する」ボタンを押します。
4. 届いた確認メールのリンクを開いて、解約を確定します。
EOF
cat > admin/offboarding.md <<'EOF'
# 退会対応 (管理者向け)

## 顧客が解約するとき

1. 設定画面を開く。
2. 「プラン」を選択する。
3. 「解約する」を押す。
4. 確認メールのリンクから、解約を確定する。

## 管理者だけが行うこと

- 監査記録を保存する。保存を終えるまで、アカウントを削除しない。
EOF
cat > docs/design/cancel-flow.md <<'EOF'
# 設計書: 解約フロー

利用者の解約は次の順で進む。

1. 設定画面を開く。
2. 「プラン」を選ぶ。
3. 「解約する」を押す。
4. 確認メールのリンクを開いて、解約を確定する。
EOF
```

コードコメントと設計書以外のmdファイルに /dry-ssot-text を実行する。正本は `guide/cancel.md` にする。
