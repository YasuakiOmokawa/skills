# review-plan-diff

確定プラン (`/finalize-plan` 出力)、または DD 該当タスクを転記した簡易プランと実装後の diff を突き合わせ、実装漏れ・仕様逸脱・計画外差異を Critical/Major/Minor で判定する検査。判定は `agents/plan-diff-reviewer.md` が行う。

## Arguments

`$ARGUMENTS`: 確定プランファイルパス (省略可) 起点ブランチ (省略可)

## ワークフロー

### Step 1: 入力の特定

1. **確定プランファイルパス**: 以下の優先順で決定する。
   - `$ARGUMENTS` が指定されていればそれを採用する (委譲実行時は起動プロンプト本文で明示されたパスを `$ARGUMENTS` と同格に扱う)
   - 省略されている場合、現在のセッションコンテキストに既出のプランファイルパス (典型的には `~/.claude/plans/*.md`、`/finalize-plan` の出力先) があればそれを採用する (単独起動時のみ有効な経路)
   - どちらも無い場合、`AskUserQuestion` が利用可能ツール一覧にあれば以下を表示してユーザーに尋ね、返答を待って停止する。無ければ「## 委譲実行」節に従う:
     「突き合わせ対象の確定プランファイルパスを教えてください。」
2. **分析ファイルパス**: プランファイルの拡張子前に `.analysis` を挿入して導出する (例 `feature-xxx.md` → `feature-xxx.analysis.md`)。存在しない場合は Step 3 の起動プロンプトに「無し」と渡し、AC/MECE分析結果との突き合わせは対象外にする。
3. **対象リポジトリの絶対パス**: 起動プロンプト本文で明示されていればそれを採用する (委譲実行時)。明示が無ければ現在の作業ディレクトリを採用する (単独起動時)。nested 起動する `plan-diff-reviewer` は呼び出し元の作業ディレクトリを引き継がないため、Step 3 の diff 取得コマンドにはこの絶対パスを `git -C` で明示する。

### Step 2: 比較対象 diff の決定

1. **起点ブランチ**: diff の比較元 (親) となるブランチを指す。プラン記載の実装対象ブランチ (作業ブランチ、diff の HEAD 側) とは別物であり、両者を混同しない。以下の優先順で決定する:
   - `$ARGUMENTS` の第 2 引数、または委譲実行時に起動プロンプト本文で明示されていればそれを採用する
   - プランファイルまたは同ディレクトリの `<プラン名>.preflight.md` に「起点ブランチ」、または diff の比較元を指す同義のラベル (「比較元ブランチ」「ベースブランチ」等) 付きで記載されていればそれを採用する。「ブランチ戦略」等の節が作業ブランチ (実装を継続する現ブランチ) を説明しているだけの記載は、比較元を指すラベルが無い限り採用しない
   - 記載が無ければ、`AskUserQuestion` が利用可能ツール一覧にあればユーザーに尋ね、返答を待って停止する。無ければ「## 委譲実行」節に従う:
     「diff の起点ブランチを教えてください (例: develop、main)。」
   - 起点ブランチの確定に `git branch` 等リポジトリの分岐関係の参照は用いない。分岐関係の推定は本 skill の対象外であり、上記の情報源のみで判断する
2. 比較対象は `<起点ブランチ>..HEAD` とする。

### Step 3: レビューエージェント起動

`Task` ツール (`subagent_type: general-purpose`、本リポ標準の dispatch パターン) で `plan-diff-reviewer` を 1 体起動する。`Task` という名前のツールが無くても、サブエージェントを起動できるツール (`Agent` 等、名称は環境により異なる) があればそれを使う。以下これらを「サブエージェント起動ツール」と呼ぶ。

- **同期実行する**: Step 4 でエージェントの出力を提示するため、結果を待って受け取る。ツールが既定で非同期 (background) 起動する場合は同期実行のオプションを指定する。
- **命名・チーム所属を指定するパラメータ (`name` 等) は付けない**: 委譲実行 (自分自身が subagent) の状況では nested 起動が拒否される。
- **指示ファイル行は絶対パスで渡す** (単独起動・委譲実行のいずれでも): 下記プロンプトの指示ファイル行を、今読んでいる本 SKILL.md と同じディレクトリにある `agents/plan-diff-reviewer.md` の絶対パスに書き換えてから起動する (既に絶対パスへ展開済みならそのまま)。テンプレートの `${CLAUDE_PLUGIN_ROOT}/skills/review-plan-diff/` と本 SKILL.md のディレクトリは同一の場所を指すので、書き換え後のパスは `/agents/plan-diff-reviewer.md` で終わり `skills/review-plan-diff/` は 1 回だけ現れる。
- **サブエージェント起動ツールが利用可能ツール一覧に無い場合**: 本 Step は実行せず「## 委譲実行」節の fallback (自分で判定する) に切り替える。

```
Task:
  subagent_type: general-purpose
  prompt: |
    あなたはプラン突き合わせレビューエージェントです。
    以下の指示ファイルを読み、その内容に従ってレビューを実行してください。

    指示ファイル: ${CLAUDE_PLUGIN_ROOT}/skills/review-plan-diff/agents/plan-diff-reviewer.md

    ## 入力
    - 確定プランファイルパス: {Step 1 で特定したパス}
    - 分析ファイルパス: {Step 1 で導出したパス、無ければ「無し」}
    - 対象 diff の取得コマンド: git -C {Step 1 で特定した対象リポジトリの絶対パス} diff {Step 2 で決定した起点ブランチ}..HEAD

    プラン記載の各項目 (確定プランなら AC・QA-ID カバレッジマトリクスで定義された変更範囲、簡易プランならプラン本文に列挙された項目) と diff を突き合わせ、結果は指示ファイルの「結果出力」フォーマットに従って返してください。
```

### Step 4: 結果報告

エージェントの出力を正本として、そのままユーザーへ提示する。そのうえで総合判定に応じて次の一文を添える:

- **Critical あり**: 該当する乖離 # を指して修正を促す
- **Major/Minor のみ**: 修正するかどうかの判断をユーザーに委ねる
- **乖離なし**: そのまま完了報告する

## 委譲実行 (subagent として起動された場合)

`AskUserQuestion` が利用可能ツール一覧に無い場合、Step 1・2 の「ユーザーに尋ね、返答を待って停止する」は以下に読み替える。単独起動時の動作は変えない。

- **入力が確定できない場合**: 質問文を出して待つ代わりに、「不足入力: 確定プランファイルパス」または「不足入力: 起点ブランチ」を最終メッセージに含め、その場で終了する (返答を待つために停止しない)。
- **サブエージェント起動ツール (Step 3) が利用可能ツール一覧に無い場合**: Step 3 は実行できないため、`agents/plan-diff-reviewer.md` を Read し、そのワークフローに従って自分で突き合わせ判定を行う。
- **成果物の返し方**: Step 4 の「ユーザーへ提示」は、突き合わせ結果の全文を最終メッセージに含めて呼び出し元へ返すことを指す。結果ファイルは作らない。
