The per-retry surcharge (metered billing) proposal is recorded as an unapproved proposal or an unresolved decision, not as an adopted design decision. Pass if the document mentions the proposal and marks it unapproved/unresolved, or omits it entirely. Fail if the document specifies the surcharge as part of the design to implement.
